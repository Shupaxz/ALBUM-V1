05

ไฟฟ้าและแม่เหล็ก (Electricity & Magnetism)

5.1 ไฟฟ้าสถิต

START EXAM 🎯
แรงคูลอมบ์
$$F = k\frac{q_1q_2}{r^2}$$
START EXAM 🎯
สนามไฟฟ้า
$$E = \frac{F}{q} = k\frac{Q}{r^2}$$
START EXAM 🎯
ศักย์ไฟฟ้า
$$V = k\frac{Q}{r}$$
START EXAM 🎯
พลังงานศักย์ไฟฟ้า
$$U = qV = k\frac{q_1q_2}{r}$$
START EXAM 🎯
ความจุไฟฟ้า
$$C = \frac{Q}{V}$$
START EXAM 🎯
ตัวเก็บประจุแผ่นขนาน
$$C = \frac{\varepsilon_0 A}{d}$$
START EXAM 🎯
พลังงานสะสมในตัวเก็บประจุ
$$U = \frac{1}{2}QV = \frac{1}{2}CV^2 = \frac{Q^2}{2C}$$

5.2 ไฟฟ้ากระแสตรง

START EXAM 🎯
กระแสไฟฟ้า
$$I = \frac{\Delta Q}{\Delta t} = nevA$$
START EXAM 🎯
กฎของโอห์ม
$$V = IR$$
START EXAM 🎯
ความต้านทาน
$$R = \rho\frac{L}{A}$$
START EXAM 🎯
กำลังไฟฟ้า
$$P = IV = I^2R = \frac{V^2}{R}$$
START EXAM 🎯
แรงเคลื่อนไฟฟ้า (EMF)
$$E = I(R+r)$$

5.3 แม่เหล็กไฟฟ้า

START EXAM 🎯
แรงแม่เหล็กกระทำต่อประจุ
$$F = qvB \sin \theta$$
START EXAM 🎯
รัศมีวงโคจรประจุ
$$r = \frac{mv}{qB}$$
START EXAM 🎯
แรงแม่เหล็กต่อลวดตัวนำ
$$F = ILB \sin \theta$$
START EXAM 🎯
ฟลักซ์แม่เหล็ก
$$\Phi = BA \cos \theta$$
START EXAM 🎯
แรงเคลื่อนไฟฟ้าเหนี่ยวนำ
$$\varepsilon = -N\frac{\Delta \Phi}{\Delta t}$$
START EXAM 🎯
หม้อแปลงไฟฟ้า (อุดมคติ)
$$\frac{V_1}{V_2} = \frac{N_1}{N_2} = \frac{I_2}{I_1}$$

5.4 ไฟฟ้ากระแสสลับ

START EXAM 🎯
ค่ายังผล (RMS)
$$V_{rms} = \frac{V_{max}}{\sqrt{2}}, \; I_{rms} = \frac{I_{max}}{\sqrt{2}}$$
START EXAM 🎯
ความต้านทานเชิงเหนี่ยวนำ (L)
$$X_L = \omega L = 2\pi fL$$
START EXAM 🎯
ความต้านทานเชิงความจุ (C)
$$X_C = \frac{1}{\omega C} = \frac{1}{2\pi fC}$$
START EXAM 🎯
ความต้านทานเชิงซ้อน (Z)
$$Z = \sqrt{R^2 + (X_L - X_C)^2}$$

6.1 ฟิสิกส์อะตอม

START EXAM 🎯
พลังงานควอนตัม (โฟตอน)
$$E = hf = \frac{hc}{\lambda}$$
START EXAM 🎯
โฟโตอิเล็กทริก
$$E_k(max) = hf - W$$
START EXAM 🎯
ระดับพลังงานไฮโดรเจน (Bohr)
$$E_n = -\frac{13.6}{n^2} \, \text{eV}$$
START EXAM 🎯
ความยาวคลื่นเดอบรอยล์
$$\lambda = \frac{h}{p} = \frac{h}{mv}$$
START EXAM 🎯
หลักความไม่แน่นอนไฮเซนเบิร์ก
$$\Delta x \Delta p \ge \frac{h}{4\pi}$$

6.2 ฟิสิกส์นิวเคลียร์

START EXAM 🎯
พลังงานมวลสาร (Einstein)
$$E = \Delta mc^2$$
START EXAM 🎯
กัมมันตภาพ (Activity)
$$A = \lambda N$$
START EXAM 🎯
การสลายตัวของธาตุกัมมันตรังสี
$$N = N_0 e^{-\lambda t}, \; A = A_0 e^{-\lambda t}$$
START EXAM 🎯
ครึ่งชีวิต (Half-life)
$$T_{1/2} = \frac{\ln 2}{\lambda} = \frac{0.693}{\lambda}$$
START EXAM 🎯
มวลที่เหลือจากการสลาย
$$N = \frac{N_0}{2^n}, \; n = \frac{t}{T_{1/2}}$$
